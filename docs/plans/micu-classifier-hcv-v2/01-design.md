# 设计：让学生学到一致、可执行的行为

状态：规划。证据与适用范围见 [04-evidence.md](04-evidence.md)。

## 已确认的项目约束：每个 query 图像一种 pattern

用户明确说明这是实际实验经验，本项目按此执行，不再把它列为待证明建议。
原始实验编号、对照规模和效应量尚未提供；这不影响遵循约束，但不能编造
量化收益或把它归因于某家公司的报告。

同一最终训练包及其混合训练入口中，以 image_group_id 归并同一 query 图像，
包括同图 EN/ZH、Open/Option、候选条件、数据增强和历史衍生版本。每组只能
分配一个 primary_pattern。不能通过改变 query_id 或文件路径规避。

pattern 是学生要学习的核心行为，例如有证据确认、候选重排、高置信纠错、
候选外发现或合理停止；route 是实际走过的工具路径；tool_count 是调用次数。
三者分别记录，不互相替代。一条“候选外发现”轨迹可以同时调用分类器、
两次检索并停止，仍是一个主 pattern。

最初 P1–P10 存在语义交叠。审核保留 observed_patterns 作为多标签诊断，
根据实际决策转折确定唯一 primary_pattern，不能仅改标签把冲突行为合并。
例如 P4 高置信纠错可伴随 P8 检索噪声，后者只作辅助诊断。无法确定主模式
或同图候选轨迹要求不兼容的行为时，送人工或不入包，不强行重写结论。

建议首版每图导出一条轨迹以简化落实；“只能一条文本”是实现建议，不是
用户已经确认的实验结论。同 pattern 多条语言变体若保留，必须控制同图总
采样权重。不同实验臂可以使用同一图像的不同衍生数据，但不得混成同一训练包；
实验间保持固定主 pattern，检验的是监督方式。原始轨迹、失败及其他模式
留在审计归档，不删除，不计作新增独立图像或稳定性样本。

### 行为判定规范：标签唯一只是第一层检查

每条候选记录另存私有 behavior_signature：触发条件、决策前可见状态、
核心动作、支持/反证引用、最终状态。审核先核对这些事实，再分配主 pattern，
不能由 target_pattern 倒推应该生成什么。以下是首版判定规则，阈值和
边界夹具在 E0 冻结；它是审核规范，不是写给教师的逐图思维模板。

| 主 pattern | 可审核触发条件 | 核心动作和必要证据 | 同模式允许变化／冲突反例 |
| --- | --- | --- | --- |
| P1 有证据确认 | 候选存在且有视觉支持 | 核对后采纳，引用实际可见特征 | 可直接确认或检索确认；只复述高分不合格 |
| P2 低置信确认 | 分类得分处于开发集冻结的低分区间 | 用特征支持候选，不能把低分等同 Unknown | 措辞和检索次数可变；将同一证据下的低分直接判 Unknown 为冲突 |
| P3 候选重排 | 正确候选在 Top-5 内且原始排名非第一 | 有区分证据的重排 | 查询可变；无反证照抄第一名不属于本模式 |
| P4 高置信纠错 | 高分首选错误，分数阈值已冻结 | 以视觉/公开证据否定首选并支持修正 | 目标在候选内外均可；先验否定高分或无证据改判不合格 |
| P5 候选外发现 | 合理结论在已保存 Top-5 外 | 真实扩展搜索并核对新假设 | 可有多次查询；将检索前未知答案写进早期决策不合格 |
| P6 模拟 Unknown | Known 留出类被分类器监督排除 | 核对 Known 不匹配，并按任务约定回答 | 可高分或低分误归；把工具失败当 Unknown 不合格 |
| P7 来源冲突 | 分类器与检索产生不同假设 | 按区分性证据和来源质量解决冲突 | 两种来源均可胜出；固定偏袒某来源不合格 |
| P8 检索噪声 | 实际返回无关、重复或缺乏区分性 | 舍弃噪声、调整查询或有理由停止 | 可更换来源；把“有返回”当新增证据不合格 |
| P9 名称与粒度 | 别名、虫态或病征/病名存在歧义 | 依可见证据规范命名，控制具体程度 | 中英文表述可变；将粒度不足硬写成精确诊断不合格 |
| P10 证据不足 | 图像/公开证据无法支持任务所需结论 | 有理由停止，Open 专用 | Known 也可停止；仅因预算耗尽或工具故障不自动归此模式 |

P1–P10 并非天然互斥。优先将导致最终判断改变或停止的核心行为作为主
模式；多个转折同等重要时送人工或排除，不能临时靠任意优先级保证配额。
高/低分阈值只在私有审核侧作模式归类，不是 Known 概率或在线放行阈值。

同图合并前还需行为一致性检查：相同可见状态不能同时要求无条件采纳和
无条件否定候选。不同真实工具返回导致不同后续动作不自动算冲突，应按
各自证据时间核对。跨语言、题型或增强改变了可见信息时，首版宁可保留
一个审核完整的代表轨迹，不能仅因 primary_pattern 字符串相同就合并。

最低交付为上述十类的正例和冲突反例夹具、两份独立标注及分歧裁决记录。
确定性检查验证身份、事件和字段；语义一致性由审核者判定。重复独立
标注先用同一已保存材料进行离线/人工核查；若新增模型审核请求，必须
另计预算，不能在每轨迹一次私有审核限制外隐式循环。

## 近似分布的实际含义

首轮学习经过验证的教师经验分布：真实图像/问题 → 自然产生的判断与动作
→ 实际工具返回 → 后续判断。无需教师完整 logits，不能把分类器 softmax
当作生成模型的 token 分布。整体改写和补全会改变训练分布，应记录生成
方式、模型、解码参数及筛选条件，不再称其为未经处理的真实分布。

学生易学性优先定义为：相同计算/监督 token 下，独立开发集的正确性、
合法动作、终止、纠错和工具效率改善，且 Direct/Unknown 不退化。辅助看
同一公共目标上的验证 NLL、学习曲线、不同随机种子方差和长度分组表现。
不同措辞/长度目标的原始 NLL 不直接横比；低 NLL 也可能只是答案变短、
信息被删或模式坍缩，不能单独筛掉困难但重要的样本。

## 需要补充的硬约束

| 约束 | 落地检查 | 原因 |
| --- | --- | --- |
| 同图主 pattern 唯一 | 联合所有训练输入按 image_group_id 分组，主模式集合大小为 1 | 用户已验证的项目经验 |
| 因果可见性 | 每段判断只引用此前已可见图像/问题/工具证据 | 改写不能制造事后先知 |
| 工具事实可追溯 | 参数、返回、次序、ID 与原始事件账本关联 | 文本润色不等于实际执行 |
| 审核与生成隔离 | 私有标签和审核原因不回流生成或改写请求 | 防止答案泄漏和反复迎合审核 |
| 训练部署一致 | 共用工具 schema、renderer、终止规则，检查实际 token/role/mask | 本地已有格式错配失败记录 |
| 图像处理一致 | 版本化裁剪、分辨率、图像占位符与处理器 | 避免教师依据学生看不到的细节 |
| 分割与来源隔离 | SHA/来源/近重复；107 Known/104 Unknown 和冻结 registry | 正式 Unknown 不进入 SFT，最终测试仅作最终评测 |
| 资格和交付隔离 | 两轮稳定性、人工确认；未知交付先核验，不重放 | 继承现行准入，不因改写获得训练资格 |

正文解释是模型公开生成、可审计的监督，不假定 API 返回了内部完整思维过程。
缺失的内部推理不能冒充原始轨迹；模型补全得到的内容要明确标为衍生生成。

## 需要优化但不预设结论的部分

1. 模型原稿、整体改写和前缀补全：减少人工拼接模板，保留事实和有效反证；
   哪一种最易学由学生实验决定，不能只让改写模型给自己打分。
2. 统一 system prompt：优先统一语义合同和部署协议，具体措辞可由模型从
   合格轨迹中提出，再用开发集选择；不是所有教师必须字节相同的 system 消息。
3. 样本质量：正确答案之外查视觉证据、工具有效性、最终闭合、细粒度名称
   和合理不确定性。公开证据薄弱的类别应处理图像/知识库问题，而非堆长解释。
4. 保留能力：混入独立图像的简洁 Direct、低成本确认和不充分证据样本。
   它们仍各自只有一个 pattern；保留比例在开发集选，不照搬公司的领域比例。
5. 长度与 loss：按实际 assistant mask 统计解释/动作/最终答案 token 占比。
   是否加权最终答案、截短冗余或采用课程学习需单变量对照，不默认长链更优。

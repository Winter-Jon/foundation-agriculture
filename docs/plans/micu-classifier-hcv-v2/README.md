自主工具执行衡量；不以文字更整齐、训练 loss 更低或轨迹更短替代。

## 起点与待决策项

- 基线：Micu 自然生成并筛选、SFT；不将获取真实概率接口设为前置阻塞。
- 先固定部署条件：初始图像、问题和任务协议，分类器/检索可选调用，候选不免费预注入。固定权重做小规模路由可运行性诊断。
- 首要表达对照 T1a：原稿与模型整体改写，固定工具事实和核心动作，检验表达是否更易学。
- 单列补全对照 T1b：同一公开前缀下的原后缀与新补全，两臂先采用后缀监督；新动作/证据收益与表达效果分开解释。
- 通过现有资格门槛后，用学生实验选择数据工艺；再系统优化统一指令、路由和递增预算。各训练包均满足每图单一 pattern。
- 硬边界来自每图单一 pattern 的项目经验，以及既有数据隔离、真实工具证据、部署可见性、预算和训练资格。
- 四条原路线保留：A 验证候选价值，C 改善采样，B 学习工具策略；D 在移除分类器后重新生成并验证。

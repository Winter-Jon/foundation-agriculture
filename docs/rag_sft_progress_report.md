# 农业多模态大模型 RAG SFT 进展汇报

汇报日期：2026 年 8 月 8 日

## 一、当前结论

目前，RAG 数据生成、知识检索、模型训练和统一评测已经跑通。现有实验暴露出一个比较明确的问题：早期 RAG SFT 让模型学会了调用知识库，却没有带来诊断准确率的提升，原有的视觉识别能力反而有所下降。

统一测试集包含 618 个中英文病虫害问答，开放题和选择题各 309 个。实验结果如下：

| 实验 | 总体准确率 | 开放题准确率 | 选择题准确率 |
|---|---:|---:|---:|
| 直接识别基线 | 65.21% | 41.10% | 89.32% |
| 已完成 RAG SFT 路线 A：从直接识别模型继续训练 | 43.69% | 38.83% | 48.54% |
| RAG SFT 早期独立训练路线 | 9.71% | 8.74% | 10.68% |

检索系统本身运行正常。早期 RAG 评测共完成 1,693 次知识库调用，调用成功率为 100%；在真实图像测试中，正确类别排在第 1 位，相似度为 0.9519。这说明目前的瓶颈并不在“能不能检索”，而在训练数据有没有教会模型把图像判断、检索证据和最终答案衔接起来。

现阶段的重点是迭代 RAG SFT 数据，先通过小规模对照训练确认有效，再扩大数据量。

## 二、早期 RAG SFT 为什么失败

一个直接原因是，早期训练数据过于强调工具调用和长推理。模型更容易记住固定的检索流程，却没有稳定学会如何根据图像作出初步判断、如何使用检索证据，以及最后怎样规范作答。这个问题在选择题上尤其明显：准确率由 89.32% 降至 48.54%。

数据分布也不够合理。直接识别数据共 2,114 条，中英文基本平衡；早期 RAG 数据共 873 条，却全部是英文，其中病害 642 条、虫害 231 条。中文、虫害、选择题和不同检索情形覆盖不足，训练后容易出现语言和作答方式的偏移。

另一个问题是，基础格式检查不能反映样本是否真的适合训练。上一轮试验生成 216 条候选轨迹，其中 133 条通过基础协议，答案准确率和检索成功率均为 100%。但继续检查内容后，仍然发现：

- 23 条入选中文样本使用相同的检索前模板；
- 部分直接识别回答长达 7,052 个字符，包含重复标题和无关知识；
- 42 条入选 RAG 样本中，有 11 条的目标证据只排在第 2 至第 4 位，存在根据已知标签挑选证据的风险；
- 旧数据缺少证据不足时拒绝作出确定判断的训练与评测。

也就是说，这些样本虽然格式正确，却可能让模型学到固定模板、标签提示和冗长表达，而不是可迁移的检索判断能力。

## 三、SFT 数据版本迭代

针对这些问题，我们已经实际完成了五轮数据 Pilot。V1 至 V5 每一版都对应一次“生成小批量数据—检查问题—修改方法—重新验证”的内层循环，并不是五次模型训练。因此，表中记录的是每轮循环解决了什么，以及下一轮继续处理什么。

| 数据版本 | 主要修改 | 主要问题 |
|---|---|---|
| V1 | 建立均衡采样和多候选择优流程 | 纠错没有真实反映在回答中，候选筛选不足 |
| V2 | 将图像观察和候选判断前移，加入显式纠错 | 仍有失败调用、语言混杂和图像重叠 |
| V3 | 分离中英文生成，并加入备用目标和图像去重 | 中文检索前推理模板化，部分数据类型不足 |
| V4 | 加入图像相关推理、语义检查和检索预筛选 | 当前数据质量已明显改善，但仍需完成最终复核 |
| V5 | 区分不同检索路线，并在采样前验证路线是否有效 | 正在比较有答案约束和无答案提示两种生成方式，尚未进入 SFT |

五轮循环逐步把问题从格式和工具调用，推进到图像相关推理、真实纠错、数据均衡、语义质量，以及检索路线和生成方式是否有效。

## 四、RAG SFT 的迭代路线

### 外层循环：决定是否扩大训练

项目按“数据 Pilot—小规模消融 SFT—统一评测”推进。评测证明 RAG 有收益，才扩大数据和训练规模；如果没有收益，就回到数据 Pilot，开始下一轮修改。当前 V1 至 V5 都属于外层循环中的数据 Pilot 阶段，新数据尚未进入正式消融 SFT。

### 内层循环：把一版数据逐步做可靠

V1 到 V5 是内层循环的历史迭代。接下来按照最新计划，将相关工作合并为三个步骤。

1. **先完成基础数据和检索规则。** 统一处理均衡选样、图像相关推理、中英文隔离、图像去重、检索预筛和语义质检。不同样本使用视觉、文本、图文联合或名称确认等合适的检索路线。名称检索只用于确认已经检索到的类别，不能直接拿标准答案查询。这些属于数据生产的基础规则，合并检查，不再分别做实验。

2. **重点验证两种生成方式和真实纠错。** 对同一批图像分别生成两类数据：一类允许教师模型看到标签，用于辅助质量控制，但标签不能提前出现在查询和回答中；另一类完全不向教师模型提供标签，只在生成结束后验收答案。两条路线分别保存和检查，比较答案质量、证据支持和标签泄漏。纠错样本还要保留初始判断、修正结果和对应证据，只有判断真正发生变化才算有效。

3. **补充自主选择和拒答数据。** 在前两步稳定后，加入高置信度直接回答、需要 RAG、证据冲突时继续查证，以及证据不足时拒答等样本。目标是让模型学会什么时候使用知识库，而不是遇到所有问题都检索。

每一步先用小规模 Pilot 检查。基础规则有问题就直接修正；两种生成方式、纠错或拒答能力需要比较效果的，则单独保留验证结果。内层数据通过后，再进入外层的 **P3 消融 SFT 与评测**。

## 五、V5 最新采样前案例

V5 中有一条中文开放题，目标类别是“无花果叶枯病”。图像中的叶片呈明显的掌状分裂，可以看到多处不规则褐色坏死斑。前几版通常使用较为固定的检索流程，V5 则先判断这张图像更适合哪种检索方式。

这张图像采用“先做图文联合检索，再确认类别名称”的路线。在正式生成对话前，系统先测试了这条路线：正确类别排在第 1 位，相似度为 0.82。因此，这张图像和对应的检索方式可以进入下一步样本生成。

## 2026-06-13 16:35:08 CST - AgriNet wiki Milvus multimodal search API and sparse-name index

### Context
Deploy `datasets/AgriNet-1K/wiki` into Milvus and expose a reusable API for multimodal class search over AgriNet wiki knowledge. The search service needed SigLIP text/image query embeddings, multi-vector hybrid search, sparse class-name lookup, configurable presets, and stable route naming.

### Changes
- Added Milvus Lite database artifact at `outputs/milvus/agrinet_wiki_lite.db` and rebuilt collection `agrinet_wiki_siglip2` with 320 class rows.
- Updated `tools/milvus/ingest_agrinet_wiki.py` so each wiki class is one row with typed fields, `text_vector`, `image_vector`, and `sparse_vector`.
- `text_vector` and `image_vector` are generated with local SigLIP2 model `models/siglip2-so400m-patch16-naflex`.
- Added `sparse_text` / `sparse_vector` for class-name and alias lookup only: `english_name`, `chinese_name`, `alias_en`, and `alias_cn`.
- Removed `code` from `embedding_text` and sparse text; `code` remains a scalar metadata/filter field.
- Added `tools/milvus/search_agrinet_wiki.py` for CLI search and query embedding generation.
- Added `tools/milvus/search_api.py` using standard-library HTTP server, with one resident SigLIP2 model and one Milvus client per process.
- API routes now use preset names:
  - `GET /health`
  - `POST /search`
  - `POST /search/balanced`
  - `POST /search/visual`
  - `POST /search/semantic`
  - `POST /search/name`
  - `POST /search/rrf`
- Deprecated route names such as `/search/image`, `/search/images`, and `/search/text` are not active in the final route set.
- Supported request inputs include `text`, `texts`, `image_path`, `image_paths`, `image_base64`, and `image_base64_list`.
- Presets:
  - `balanced`: weighted, text `0.35`, image `0.45`, sparse `0.20`.
  - `visual`: weighted, text `0.10`, image `0.80`, sparse `0.10`.
  - `semantic`: weighted, text `0.70`, image `0.00`, sparse `0.30`.
  - `name`: weighted, text `0.00`, image `0.00`, sparse `1.00`.
  - `rrf`: `RRFRanker`, with the balanced weights retained in metadata.
- Request-level overrides for `ranker`, `text_weight`, `image_weight`, and `sparse_weight` are supported, including `0.0` values.

- Added/updated `tools/rag_distill/convert_to_student_sft.py` so raw teacher traces are rebuilt into clean student SFT rows with only user prompt, canonical `tool_call`, successful `tool_response`, and final assistant answer.

- Updated `tools/milvus/search_agrinet_wiki.py` so API-facing simplified hits and CLI output no longer include `code`; alias fields are returned for name matching.
- Updated `tools/rag_distill/schema.py` wording so the RAG tool describes class-name and alias lookup, not code lookup.

## 2026-06-14 17:48:38 CST - Refine v5 premature name-query boundary

The unsafe case is querying the complete private target class name before any tool response supports it.

- Updated the evidence retry prompt to state that neutral names inferred from evidence are allowed, but the complete private target class name is not allowed until it appears in tool evidence.
- Extended `tools/rag_distill/name_eval_smoke.py` to assert that a neutral `healthy cherry leaf` query is allowed while a premature exact `Cherry Normal leaf` query is rejected.

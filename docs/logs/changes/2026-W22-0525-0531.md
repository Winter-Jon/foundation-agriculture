## 2026-05-29 19:45:00 CST — Large-batch bilingual distillation pipeline

### What

Built a large-batch bilingual (EN/ZH) data distillation pipeline for AgriNet-1K disease/pest classes, with separated Chinese and English teacher collection and student SFT generation.

### Why

The initial distillation round produced only 217 samples (1 per class) with English-only SFT data. This round expands to ~2100 samples (10 per class) and generates two independent SFT datasets — pure English and pure Chinese — for bilingual VLM training.

### How

#### Pipeline Architecture

1. **Data preparation**: `tools/vloom_agrinet/prepare_disease_pest_data.py` with `--reuse-pairs` (skip PyTorch computation) and `--random-sample-classes N` (for test batches)
2. **English teacher collection**: VLooM with `agrinet_contrast_cot.j2` prompt template
3. **Chinese teacher collection**: VLooM with `agrinet_contrast_cot_zh.j2` prompt template (Chinese reasoning chain requested)
4. **Bilingual SFT conversion**: `tools/vloom_agrinet/convert_to_sft_messages.py` with `--output-sft-en` and `--output-sft-zh` flags

#### Key Design Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Bilingual generation | Separate teacher runs (EN + ZH) | Single-pass translation loses reasoning quality; separate teacher runs produce native-quality chains in each language |
| Chinese think synthesis | Empty `original_think` for ZH SFT | Forces synthesis from structured JSON fields using Chinese section titles, avoiding English title leakage |
| Query format | Open-ended questions only (no candidates) | Better for open-domain recognition training |
| Sample count | 10 per class (~2100 total) | Balance between data diversity and API cost |
| Python environment | `.venv-py312` created with `uv` | Compute nodes only have Python 3.12; original `.venv` is Python 3.10 |

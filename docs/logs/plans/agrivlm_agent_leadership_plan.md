# AgriVLM-Agent：面向农业细粒度识别与智能分析的多模态大模型 Proposal

## 1. 研究背景与核心问题

农业生产正在面临更复杂的感知与决策需求。田间图像、虫体局部图像、遥感影像和农产品图像中往往包含大量细粒度对象：作物、害虫、益虫、杂草、农机、品质缺陷以及环境背景共同出现。农业专家在判断这些对象时，依赖的不只是视觉外观，还包括物种分类、寄主关系、发生场景、危害方式和管理经验。相比之下，现有农业视觉模型大多停留在封闭标签识别，难以回答“这是什么、为什么是它、它对农业生产意味着什么、还需要什么证据”这一类更接近实际生产的问题。

通用多模态大模型为农业智能分析带来了新的可能，但其能力边界也很清楚：它们能够生成流畅描述，却难以稳定区分农业细粒度类别；能够识别“昆虫”或“植物”，却缺乏害虫/益虫属性、寄主作物、危害部位、质量等级等农业知识；能够给出判断，却常常缺少可审查的视觉证据和知识依据。因此，农业场景需要能够把视觉证据、农业知识和专业工具组织起来的多模态分析系统。

AgriNet-1K 为这一方向提供了重要基础。该数据集包含 1020 个农业相关类别，覆盖作物、昆虫、微生物、农机、花卉、水产等对象。其价值不仅在于类别规模，更在于可以将类别标签进一步连接到中文名、拉丁学名、农业功能、相似类别差异和应用场景等知识。同时，项目还需要整合大规模农业下游任务数据集，包括检测、分割、计数、遥感监测和质量检测等数据，用于训练垂直视觉工具并验证真实农业任务中的分析能力。

本项目拟构建 **AgriVLM-Agent**：一个面向农业细粒度识别与智能分析的知识增强、工具增强多模态大模型系统。项目以农业细粒度类别和知识库为基础，以可验证证据链训练提升细粒度判断能力，以大规模下游任务数据训练垂直视觉工具，最终让大模型能够整合视觉证据、农业知识和工具结果，形成可解释、可审查、可落地的农业分析结论。

## 2. 创新性定位

本项目面向农业专家和 AI 研究者共同关心的问题：如何把农业知识、细粒度视觉识别和专业工具真正整合到一个可验证的智能系统中。其创新性体现在以下四个方面。

1. **从标签数据到农业知识增强多模态资源**
   AgriNet-1K 将被扩展为农业细粒度知识资源。每个类别不仅对应图像标签，还对应分类学、农业功能、寄主或应用场景、危害或价值、相似类别差异等信息。大规模下游任务数据则补充分割、检测、计数、遥感和质量检测等空间标注与任务监督。两类数据结合后，可以同时支撑“识别是什么”和“判断其农业意义”两个层面的模型训练。

2. **细粒度可验证推理**
   Fine-R1 的核心启发是：细粒度识别应被建模为可验证的视觉推理问题。本项目将这一思路迁移到农业场景，要求模型不仅输出类别，还要输出候选类别、视觉依据、知识依据、相似类别差异和不确定性。对于农业专家而言，这种输出形式更接近实际诊断过程：先观察特征，再比较相似对象，最后结合知识给出判断。

3. **知识增强与工具增强结合的农业分析范式**
   农业任务往往需要定位、分割、计数和量化。虫害需要虫体检测、局部裁剪和虫口风险估计，作物计数需要目标定位，遥感监测需要地块级分析，质量检测需要缺陷区域和等级信息。本项目将 VLM 定位为分析中枢，将专用视觉模型作为工具：工具产生可靠证据，大模型整合证据、知识和任务目标，形成农业上可解释的判断。

4. **从准确率评测走向专家可审查的农业判断**
   农业模型的价值不能只由 Top-1 accuracy 衡量。本项目将同时评估细粒度识别、相似类别区分、农业知识一致性、证据质量、幻觉率、不确定性校准、工具调用有效性和专家评价结果。面向 Nature Food 或 Nature Communications，关键不是单一指标提升，而是证明模型判断能够被农业专家审查、复核和使用。

## 3. 总体技术路线

项目采用“两阶段 VLM + 工具增强”的路线。第一阶段训练细粒度识别 VLM，目标是先把农业细粒度类别识别能力做扎实；第二阶段在下游任务中接入垂直视觉模型，训练具备工具调用、证据整合和决策分析能力的多模态 agent。

1. **农业细粒度知识库构建**
   基于 AgriNet-1K 的 1020 类农业对象，构建结构化类别知识库。字段包括中文名、英文名、拉丁学名、分类学层级、农业功能、寄主或应用场景、视觉特征、相似类别、危害或价值等。该知识库用于 VLM 指令数据构建、推理时检索和模型输出评测。

2. **大规模下游任务数据整合**
   系统收集农业检测、语义/实例分割、作物计数、遥感监测和质量检测等下游任务数据。AgriNet-1K 已完成收集，后续重点是下游任务数据的整理、格式统一、任务标注质量检查和可用于训练工具模型的数据划分。

3. **两阶段思维链与指令数据构建**
   思维链数据分为两个阶段。第一阶段是细粒度识别思维链，服务于类别识别能力训练，强调视觉特征、候选类别对比、相似类别排除、农业属性判断和不确定性表达。第二阶段是多模态 agent 推理思维链，服务于工具调用和下游任务决策，强调任务理解、工具选择、工具结果读取、知识库检索、证据整合和最终判断。

4. **第一阶段：细粒度识别 VLM 训练**
   选择合适开源 VLM 作为基座模型，先构造细粒度识别 SFT 数据并进行监督微调，使模型达到稳定的农业细粒度识别性能。随后通过偏好优化或强化学习进一步提升候选类别判别、证据化输出、知识一致性和不确定性表达。该阶段的核心目标是证明模型具备强于通用 VLM 的细粒度识别能力。

5. **垂直模型工具套件构建**
   基于大规模下游任务数据构建农业垂直模型工具套件，而不是孤立训练单个工具。工具套件包括检测、分割、计数、遥感监测、质量检测和风险估计等模块，并统一输入输出格式、置信度表达、局部裁剪结果和可被 VLM 读取的结构化证据。第一阶段优先围绕虫害任务构建虫体检测、局部裁剪、虫口密度估计和风险判断工具；后续扩展到作物计数、作物分割、遥感监测和质量检测。

6. **第二阶段：多模态 Agent 训练**
   在细粒度识别 VLM 达到目标性能后，进一步引入垂直模型工具套件，在下游任务中训练多模态 agent。此阶段模型不仅需要具备更好的细粒度分类能力，还需要学会调用工具、读取工具输出、检索知识库、整合证据并形成完整决策。该阶段需要构造 agent 推理 SFT 数据，并继续进行偏好优化或强化学习。只有完成工具调用和证据整合训练后的模型，才称为 AgriVLM-Agent。

## 4. 实验计划与分工

项目建议分为 **计算机组** 和 **农业组** 两条线并行推进。农业组负责数据、标签、专家知识和落地场景，计算机组负责知识库、两阶段思维链、模型训练、工具集成和系统实现。两组在虫害任务上先形成闭环，再扩展到其他下游任务。

### 4.1 农业组任务

1. **数据集收集与整理**
   AgriNet-1K 已完成收集。农业组后续重点收集和整理大规模下游任务数据集，包括目标检测、语义/实例分割、作物计数、遥感监测、质量检测等。数据整理需要明确数据来源、任务类型、标注格式、作物或场景范围、类别体系和可公开性。

2. **虫害任务细粒度标签构建**
   在下游任务数据中，优先对虫害相关数据进行细粒度标签整理。现有下游数据往往只标注“虫”“昆虫”或粗类别，不能直接支撑细粒度 VLM 训练。农业组需要补充害虫/益虫属性、虫种或候选虫种、寄主作物、危害部位、虫口密度或风险等级等标签，并标注相似类别关系。

3. **专家规则与农业知识审核**
   农业组负责审核类别中文名、拉丁学名、农业功能、寄主关系、危害方式、相似类别区分点等知识，保证知识库和模型输出评测有可靠依据。

4. **落地实验设计与验证**
   农业组设计真实或半真实场景验证，包括田间虫害图像、虫体局部图像、生产环境中的复杂背景图像等。落地实验需要专家参与，重点评估模型结论是否可信、证据是否充分、风险表述是否符合农业实践。

### 4.2 计算机组任务

1. **知识库构建**
   基于农业组整理的数据和专家审核结果，计算机组负责将类别知识结构化，形成可检索、可训练、可评测的农业知识库。知识库需要支持中英文名、拉丁名、农业功能、相似类别、视觉特征和下游任务标签之间的关联。

2. **两阶段思维链与指令数据构建**
   计算机组负责构建两类数据。第一类是细粒度识别 SFT/RL 数据，包括视觉依据、候选类别对比、相似类别排除、农业属性判断和不确定性表达，用于训练识别 VLM。第二类是多模态 agent SFT/RL 数据，包括任务理解、工具调用理由、工具结果读取、知识库检索、证据整合和最终决策，用于训练真正的工具增强 agent。

3. **第一阶段 VLM 训练与验证**
   计算机组首先训练细粒度识别 VLM。该阶段包括识别 SFT、知识增强 SFT、可验证推理增强和 RL/偏好优化实验，核心目标是达到稳定的细粒度识别性能，并与通用 VLM、传统视觉模型和无知识增强模型进行对比。

4. **第二阶段 Agent 训练与验证**
   在第一阶段识别能力达标后，计算机组利用垂直工具模型和 agent 推理数据训练工具增强模型。该阶段包括 agent SFT、工具调用偏好优化或 RL、工具结果读取与证据整合训练，核心目标是在下游任务中形成完整的思维链决策能力。

5. **垂直模型工具套件构建与系统集成**
   基于农业组整理的大规模下游任务数据，计算机组训练或集成检测、分割、计数、遥感和质量检测模型，形成可被 agent 调用的工具套件。工具套件需要统一接口和输出格式，例如检测框、mask、局部裁剪图、数量、面积比例、置信度、风险等级等，并将这些结果转换为 VLM 可读取的结构化证据。第一阶段优先实现虫体检测、局部裁剪、虫口密度估计和风险判断工具。

6. **评测体系与消融实验**
   计算机组负责建立自动评测和消融实验体系。第一阶段评估细粒度准确率、相似类别组内准确率、知识一致性、幻觉率和不确定性校准；第二阶段评估工具调用正确率、工具结果利用质量、证据链完整性和最终决策可靠性。专家评估结果由农业组提供，计算机组负责汇总分析。

## 5. 第一阶段实验闭环：虫害先行

第一阶段以虫害任务作为验证场景。该任务同时具备细粒度识别、知识推理、局部目标定位和风险分析需求，能够较完整检验 AgriVLM-Agent 框架。

核心实验包括：

1. 从 AgriNet-1K 和下游任务数据中整理昆虫及虫害相关类别与图像；
2. 对下游虫害数据补充细粒度标签和农业属性标签；
3. 构建虫害知识库、细粒度识别 SFT 数据和识别思维链数据；
4. 训练虫害细粒度 VLM，进行 SFT 和 RL/偏好优化，并比较通用 VLM、传统视觉模型、仅 SFT 模型、知识增强模型和可验证推理增强模型；
5. 当识别 VLM 达到目标性能后，构建虫害垂直工具套件，包括虫体检测、局部裁剪、虫口密度估计和风险判断，并构建 agent 推理 SFT 数据和 agent RL/偏好优化数据；
6. 训练工具增强 AgriVLM-Agent，比较无工具、局部裁剪、工具结果输入和完整 agent 流程；
7. 进行专家评估和落地实验，验证模型在真实农业图像中的可靠性。

这一阶段要回答四个关键问题：农业知识是否能弥补通用 VLM 的专业短板，细粒度识别 SFT/RL 是否能达到可靠识别性能，agent 推理 SFT/RL 是否能形成完整工具调用与证据整合能力，工具协同是否能提升真实场景中的诊断可靠性。

## 6. 预期成果与论文叙事

本项目预期形成三类成果：

1. **数据与知识资源**：农业细粒度类别知识库、大规模下游任务数据整理、多模态指令数据、可验证证据链和推理评测集。
2. **模型与系统**：AgriVLM-Agent 及其工具增强版本，具备细粒度识别、知识解释、工具协同和不确定性表达能力。
3. **方法论贡献**：系统回答通用 VLM 在农业细粒度识别与智能分析中的能力边界，并验证知识增强、可验证推理训练和工具增强对模型可靠性的贡献。

面向 Nature Food 或 Nature Communications，论文叙事应聚焦为：农业智能分析需要开放、细粒度且可解释的多模态能力；通用 VLM 在农业场景中存在专业知识、细粒度识别和工具协同不足；本项目基于 AgriNet-1K 和大规模下游任务数据构建农业知识增强多模态资源，提出 AgriVLM-Agent，并通过可验证推理训练和工具协同，使模型能够在农业场景中进行更可靠的识别、解释和分析。第一阶段以虫害任务作为验证场景，展示该框架在高价值农业问题中的实用性。论文的核心贡献应突出农业多模态智能的新范式，而非局限于单个模型或单个任务的性能提升。

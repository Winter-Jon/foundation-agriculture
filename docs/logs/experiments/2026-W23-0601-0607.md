## 2026-06-01 11:10:39 CST - Known/unknown disease-pest performance vs baseline

### Objective
Split the AgriNet disease/pest VLM evaluation by known and unknown classes, then compare the final full-parameter SFT checkpoint against the untrained Qwen3-VL-4B baseline.

### Setup
- Known/unknown source: canonical strict open-domain split `datasets/AgriNet-1K/open_domain/manifests/split_info_20260527_145700_strict.json`.
- Unknown rule: `unknown` means a class absent from the strict open-domain train split. A row is unknown when its `label_code` is in the split manifest's `unknown_classes`; otherwise it is known. The strict split records `train unknown classes = 0`, so these are train-held-out classes.
- Scoring rule: unknown-class rows are still scored by whether the model predicts the original ground-truth class. Explicit `unknown` / refusal output is not counted as correct for this table.
- Baseline scored rows: `outputs/vlm_eval/qwen3_vl_4b_disease_pest/base_test/scored.jsonl`.
- Final SFT scored rows: `outputs/vlm_eval/qwen3_vl_4b_disease_pest/full_all_e5_len2048_liger_lr1e5_final_best_test/scored.jsonl`.
- Evaluation size: 618 records total, with 309 open and 309 option questions. Per question type, the split has 172 known-class records and 137 unknown-class records.

### Metrics
Accuracy is computed as `correct / count` in each question-type and known/unknown bucket, using the existing row-level `correct` field from `scored.jsonl`.

### Results

### Conclusion
The final full-parameter SFT checkpoint improves both known-class and unknown-class recognition when unknown rows are scored against their original ground-truth classes. The largest gains are in open-answer recognition: known open improves from `2.33%` to `31.98%`, and unknown open improves from `4.38%` to `37.23%`. Option performance was already high for the baseline but still improves separately in known and unknown buckets.

### Issues
- This table does not measure open-set rejection because explicit `unknown` output is not counted as correct. It measures whether the model can still identify classes that are held out from the strict open-domain train split.
- The disease/pest VLM evaluation set was generated from VLooM teacher traces rather than directly sampled from the open-domain WDS test shards, so the known/unknown split is applied by `label_code` membership in the canonical strict split.

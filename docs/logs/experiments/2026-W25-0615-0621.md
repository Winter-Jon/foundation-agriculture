Treat it as a useful debugging baseline, not as the current recommended SFT source under the latest policy.

### Next
- Improve retrieval for healthy/normal leaf classes without using unsupported exact target names, for example by tuning neutral healthy-leaf semantic prompts or retrieval embeddings.
- Add teacher API retry-on-timeout before judging acceptance, because timeout noise now dominates several rejected rows.
- Keep exact `name` lookup restricted to class names already present in real tool evidence.

### Conclusion
The final supplemented-evidence workflow is the current best validated pilot. It avoids target-name search leakage in tool calls, uses retrieved similar classes for a balanced follow-up, isolates sparse lookup to the `name` route, and can produce valid student rows when dense retrieval misses the target by adding auditable candidate evidence after retrieval failure.

The supplemented evidence is a pragmatic data-generation bridge, not a pure retrieval result. It should remain marked in tool responses and tracked separately when scaling, because it introduces teacher-side candidate evidence after a retrieval miss.

### Issues
- Acceptance is still low: 2/5 on a single Cherry Normal leaf pilot.
- The dense retrieval stack frequently returns `Apricot shot hole`, `Cherry brown spot`, `Pear fire blight`, or `Apricot Normal` instead of `Cherry Normal leaf`.
- Several rejected rows still end in teacher runtime/final-answer failures even after evidence follow-up.
- Tool responses still include `chinese_name` / Chinese aliases as evidence fields; queries are English-only, but messages are not purely English.

### Next
- Scale only after reviewing the two accepted trajectories qualitatively.
- Track supplemented evidence count/rate as a separate metric during scaling.
- Consider a retrieval-side improvement for healthy/normal leaf classes, such as explicit neutral semantic queries like `healthy leaf without spots or lesions`, before relying heavily on supplemented evidence.
- Consider hiding `chinese_name` / `chinese_aliases` from student-visible tool responses if a pure-English training set is required.

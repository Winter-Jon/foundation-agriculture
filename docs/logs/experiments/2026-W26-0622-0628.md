# Experiments - 2026-W26 (0622-0628)

## 2026-06-23 10:52:11 CST - Targeted Milvus retrieval diagnostics for Cherry Normal leaf

### Objective
Check whether the current split-collection Milvus database can retrieve `Cherry Normal leaf` with leakage-safe neutral queries and exact-name lookup.

### Setup
- Code: `tools/milvus/search_agrinet_wiki.py` functions called from an inline read-only diagnostic script.
- Data: `outputs/milvus/agrinet_wiki_lite.db`, `agrinet_wiki_siglip2_classes`, `agrinet_wiki_siglip2_images`.
- Model: `models/siglip2-so400m-patch16-naflex`.
- Text queries: neutral healthy-leaf phrases plus target-like controls including `Cherry Normal leaf` and `cherry healthy leaf`.
- Image queries: `datasets/AgriNet-1K/all/N04029/N04029_P00001.jpg` through `N04029_P00005.jpg`.
- Retrieval modes: text-only `semantic` and `name`; image-assisted `visual`, `balanced`, and `rrf`; diagnostic `top_k=20` with top-3/top-5/top-10/top-20 summaries.

### Metrics
- Whether `Cherry Normal leaf` appears in top-k.
- Rank and score for `Cherry Normal leaf` when present.
- Top retrieved alternatives for neutral healthy-leaf queries.

### Results
- DB check: `agrinet_wiki_siglip2_classes` has `row_count=320`; `agrinet_wiki_siglip2_images` has `row_count=578`.
- Exact name control works: `Cherry Normal leaf` with `name` retrieval returns `Cherry Normal leaf` at rank 1.
- Target-like semantic control works: `cherry healthy leaf` with `semantic` retrieval returns `Cherry Normal leaf` at rank 1; with `name` retrieval, `Cherry Normal leaf` appears at rank 5 behind `Cherry healthy` and `Carambola Healthy Leaf` duplicates.
- Neutral text is weak: `healthy leaf without spots or lesions`, `healthy serrated leaf`, `green serrated leaf`, `oval serrated leaf`, and `leaf with no disease symptoms` do not retrieve `Cherry Normal leaf` in semantic top-20. `healthy stone fruit leaf` is the best neutral-ish text query, returning `Cherry healthy` at rank 1 and `Cherry Normal leaf` at rank 2.
- Image-assisted retrieval remains weak for the five `N04029` query images: `visual` and `balanced` do not retrieve `Cherry Normal leaf` in top-20 for tested neutral text prompts or image-only search.
- `rrf` with `healthy serrated leaf` retrieves `Cherry Normal leaf` only at ranks 18, 18, 18, 20, and 19 across the five images; this is not useful for current `top_k=3` evidence-gated distillation.
- Common top image-assisted false positives are `Apricot shot hole`, `Apple powdery mildew`, `Walnut anthracnose`, `Apricot Normal`, and `Cherry brown spot`.

### Conclusion
The current split image collection is active, but leakage-safe visual/neutral queries still do not recall `Cherry Normal leaf` at useful ranks. Exact-name or target-like host queries can recover the target, but those are precisely the paths constrained by the current strict student-safe policy.

### Issues
- Increasing from one class image vector to 578 image rows did not solve this specific healthy-leaf retrieval failure.
- Current `top_k=3` is too shallow for `Cherry Normal leaf` under safe image-assisted queries; even the only positive image-assisted setting found it at rank 18-20.
- The best non-exact query found, `healthy stone fruit leaf`, may still be too host-adjacent for strict no-target-leak policy and needs policy review before using it in teacher-visible tool calls.
- The first diagnostic script iteration exposed a tooling footgun: `simplify_hits()` returns `english_name`/`distance`, not `class_name`/`score`, so downstream ad hoc diagnostics must use the correct fields.

### Next

2. Evaluate broader `top_k` and reranking for image search, including class-level aggregation over multiple image hits.
3. Consider whether safe candidate generation can use host-family terms such as `stone fruit` without violating target-leakage rules.
4. Do not launch another strict teacher rerun until retrieval-side changes can bring `Cherry Normal leaf` into a useful evidence window.

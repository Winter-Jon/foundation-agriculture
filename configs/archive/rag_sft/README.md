# Archived RAG SFT Configurations

These files preserve historical experiment IDs and Swift inputs exactly as recorded. They are not registered current experiments and must not be selected for a new SFT without an explicit review and a newly approved immutable freeze.

- `experiment_definitions/`: prior registered VLM experiment definitions.
- `swift_configs/`: their historical Swift runtime configurations.

Active registered controls remain under `configs/experiments/`; the current RAG SFT control is `configs/experiments/data/data-rag-sft-iteration-control-v1.yaml`.

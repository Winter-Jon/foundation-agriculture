# Archived RAG-Distillation Launchers

These Hermes and recovery shell scripts belong to closed research routes. They
are retained for run provenance only and are intentionally outside active
`scripts/rag/` and `scripts/data/` locations.

- `hermes/`: historical Hermes 1:1 collection, recovery and watcher launchers.
- `recovery/`: historical recovery-pilot launchers.

Do not run them as a current workflow. The supported current RAG collection
entry is `.venv/bin/agrinet rag submit <experiment-id> --operation distill`;
the current source is `agrinet.research.hcv`.
